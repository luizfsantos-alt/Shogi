The piece fonts are subsets reduced to the characters drawn on the pieces, so the game stays
small and works offline. Both are under the SIL Open Font License 1.1.

- `koma-kanji.woff2`: **Potta One** (heavy brush, see `OFL-PottaOne.txt`), reduced to the
  21 characters written on traditional pieces: 王玉将飛車角行金銀桂馬香歩兵龍竜全圭杏と成
- `koma-label.woff2`: **Archivo** Black (weight 900, width axis 62–125%, see `OFL-Archivo.txt`),
  reduced to `A–Z`, `0–9`, `+`, `-` and the accented capitals used in Portuguese
  (`ÃÇÉÊÍÓÔÕÚ`). It writes the piece names in reading mode.

Both were generated by the Google Fonts API with the `text=` parameter, which returns a font
holding only the requested characters:
`https://fonts.googleapis.com/css2?family=Potta+One&text=…` and
`https://fonts.googleapis.com/css2?family=Archivo:wdth,wght@62,900&text=…`.
The license texts come from the `@fontsource/potta-one` and `@fontsource/archivo` 5.3.0 packages.
