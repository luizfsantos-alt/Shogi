`koma.woff2` is a subset of **Noto Serif JP Bold** (SIL Open Font License 1.1, see `OFL.txt`),
reduced to the 21 characters written on shogi pieces:
王玉将飛車角行金銀桂馬香歩兵龍竜全圭杏と成

It was generated from the `@fontsource/noto-serif-jp` 5.3.1 files with fontTools
(`pyftsubset`-style subsetting of every file that contains one of those characters, then merged).
